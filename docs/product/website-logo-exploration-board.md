# SignalScout Logo Exploration Board

## Purpose

This board is the bridge between logo direction and actual visual exploration.

It should help us judge:

- shape quality
- originality
- fit with the current website direction
- how premium and trustworthy the brand feels
- whether the mark can scale cleanly across product and marketing use

This stage should stay black-and-white first.

## Core Brand Test

Any logo exploration should make SignalScout feel:

- evidence-led
- precise
- modern
- calm
- premium
- trustworthy

It should not feel:

- generic startup
- AI gimmick
- cyber/security product
- analytics dashboard clone
- playful consumer app

## Exploration Set

### Set A: Signal Frame

#### What to explore

- rectangular frame with one internal signal stroke
- rounded-rect frame with one internal path break
- framed corner-only construction instead of full border
- asymmetric signal path vs centered signal path

#### What to test

- can it feel branded without looking like a chart icon
- can it feel premium at favicon size
- can it sit comfortably beside the wordmark

#### Best pairing

- strongest with a restrained wordmark
- best fit for the current homepage direction

#### Success signal

Looks like a real product company mark, not a feature icon.

### Set B: Scout Lens

#### What to explore

- circular lens ring
- softened-square lens
- offset interior cut
- nested aperture-style geometry

#### What to test

- can it imply focus without reading as search or magnifier
- can it feel elegant rather than soft
- can it support hero motion later

#### Best pairing

- strongest with Mercury-style page rhythm
- good if we want slightly more visual warmth without losing discipline

#### Success signal

Feels like selective attention and judgment, not search software.

### Set C: SS Monoline

#### What to explore

- mirrored double-stroke system
- continuous-line monogram
- stacked monoline structure
- abstract dual-curve construction

#### What to test

- does it still work when reduced
- is it ownable without becoming clever
- does it still feel serious enough for the product

#### Best pairing

- strongest if the wordmark becomes very refined and minimal

#### Success signal

Feels memorable and quiet, not designerly or self-conscious.

## Black-and-White Review Criteria

Before any color is added, each logo concept should pass:

1. recognizability at small size
2. clean silhouette
3. balanced weight against the wordmark
4. no dependence on gradients or effects
5. no need for explanation

If a concept only works once color or glow is added, the base form is weak.

## Wordmark Pairing Rules

The wordmark should be judged separately from the mark.

### Wordmark goals

- stronger than the current navbar brand
- clean, compact, and confident
- feels closer to Stripe or Linear than to a soft editorial brand

### Pairing rules

- the icon must not overpower `SignalScout`
- the descriptor should stay secondary or disappear entirely
- the lockup should remain usable in a narrow navbar

## Layout Test Cases

Every logo concept should be checked in these placements:

1. navbar lockup on the website
2. favicon / app square
3. simple monochrome footer use
4. hero lockup over a light background
5. small product-shell brand placement

If it fails in one of these, it is not ready.

## Do / Don't Rules

### Do

- use crisp geometry
- favor fewer moves over more cleverness
- keep rhythm and spacing disciplined
- let the wordmark carry real weight
- optimize for trust before novelty

### Don't

- do not use orbit/globe/network-node clichés
- do not use obvious radar arcs
- do not use magnifying-glass tropes
- do not rely on AI sparkle/star language
- do not use overbuilt monograms

## Recommended Exploration Order

### Round 1

- 6 variants of `Signal Frame`
- 4 variants of `Scout Lens`
- 3 variants of `SS Monoline`

### Round 2

Take the top 2 from Round 1 and test:

- heavier vs lighter stroke balance
- sharper vs softer corner radii
- icon-only vs icon-plus-wordmark

### Round 3

Only after a winner is clear:

- explore color
- explore homepage pairing
- explore motion behavior

## Recommended Working Decision

If we want the strongest path with the least wasted effort:

- start with `Signal Frame`
- keep `Scout Lens` as the challenger
- only continue `SS Monoline` if it produces something surprisingly strong

## Next Step

Use this board to create first-pass sketches or Figma explorations in black only.

The goal is not to "finish the logo."
The goal is to identify the strongest shape system worth refining.
