## Asset System Rules

All final website imagery must be:

- original
- generated exclusively for SignalScout
- visually quieter than the UI
- aligned with the narrow product wedge

Do not generate filler assets just to fill space.

Every asset should have:

- a clear placement
- a defined purpose
- a pass/fail review rule

## Naming Convention

Use this naming pattern:

- `ss-web-<section>-<family>-v01.<ext>`

Examples:

- `ss-web-hero-interface-still-life-v01.png`
- `ss-web-credibility-evidence-board-v01.png`
- `ss-web-cta-local-signal-texture-v01.png`

If variants are explored:

- `ss-web-hero-interface-still-life-v01a.png`
- `ss-web-hero-interface-still-life-v01b.png`

## Export Guidance

Preferred working format:

- PNG for early design rounds

Possible later optimization:

- WebP for implementation

Master generation size guidance:

- generate larger than final usage when possible
- preserve enough resolution for crop flexibility

## Generation Sequence

Generate in this order:

1. `A01` hero primary
2. `A05` workspace primary
3. `A04` credibility support
4. `A03` workflow texture
5. `A06` use-case texture
6. `A08` CTA texture
7. `A07` secondary-capability strip
8. optional alternates

This order matches the highest visual leverage for homepage exploration.

## Variant Rules

For `A01`, `A04`, and `A05`, create 3 variants each:

- `a` safe
- `b` atmospheric
- `c` minimal

For `A03`, `A06`, `A07`, and `A08`, create 2 variants each:

- `a` safe
- `b` softer / more atmospheric

## Review Scorecard

Review each candidate on a 1-5 scale for:

- clarity
- elegance
- originality
- calmness
- product fit
- wedge protection

Reject any asset that:

- implies platform breadth
- feels louder than the UI
- looks generic to AI SaaS
- adds confusion instead of support

## Implementation Notes

If an asset is accepted, record:

- final filename
- section
- crop notes
- desktop placement
- mobile placement
- whether it needs a darkening or soft overlay in UI

If an asset is rejected, record:

- why it failed
- what to change in the prompt
- whether another family should be used instead

## PM Recommendation

For the first real image round, prioritize:

- `A01`
- `A05`
- `A04`

If those three land well, the rest of the homepage can be finished with much higher confidence.
