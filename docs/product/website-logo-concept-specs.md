# SignalScout Logo Concept Specs

## Purpose

These specs convert the logo directions into concrete first-pass concepts.

They are meant for:

- hand sketching
- Figma exploration
- prompt-based generation
- internal design review

The goal is to produce comparable logo concepts, not polished finals.

## Global Rules

All concepts should be explored:

- in black only first
- on white background first
- without gradients
- without shadows
- without mockup effects

Each concept should be shown in:

1. icon only
2. wordmark only
3. lockup icon + wordmark
4. navbar-scale lockup
5. favicon-scale icon

## Wordmark Baseline

Before icon variation, keep the wordmark stable enough to compare marks fairly.

### Wordmark characteristics

- `SignalScout` as one word
- modern sans base
- slightly tightened spacing
- clean uppercase/lowercase rhythm
- no playful terminals
- no exaggerated futurism

### Wordmark feel

Target:

- Stripe-adjacent confidence
- Linear-like precision
- slightly more warmth than a devtool brand

Avoid:

- soft editorial softness
- rounded toy-like geometry
- over-customized letters

## Concept Set 1: Signal Frame

### Core idea

A structured frame containing a directional signal.

### Prompt/spec version A1

- build a minimal rounded-rectangle frame
- inside it, use one rising line with a subtle bend
- keep the line abstract, not chart-like
- make the proportions compact and balanced
- pair with a clean wordmark

### Prompt/spec version A2

- use corner fragments instead of a full border
- imply a frame through 2-3 controlled segments
- place a central directional stroke inside
- keep the mark stable and architectural

### Prompt/spec version A3

- use a rectangular enclosure with one internal signal split
- create a visual feeling of review, selection, and containment
- avoid literal data visualization

### What to judge

- does it feel like a brand, not a dashboard feature
- does it feel trustworthy at small size
- does it hold beside the wordmark without overpowering it

### Kill criteria

Reject if:

- it looks like an analytics icon
- it reads as a stock “growth” mark
- it needs color to feel interesting

## Concept Set 2: Scout Lens

### Core idea

A focused inspection mark that implies attention and judgment.

### Prompt/spec version B1

- create a circular ring with one offset interruption
- suggest focus and signal inspection
- keep the geometry crisp and disciplined

### Prompt/spec version B2

- build a softened-square lens shape
- add a nested inner form with directional offset
- keep the mark modern and calm

### Prompt/spec version B3

- use a ring plus one internal cut or notch
- create a feeling of scanning without using search metaphors
- stay minimal and premium

### What to judge

- does it imply focus without becoming a magnifying glass
- does it feel elegant enough for the site
- does it support future motion nicely

### Kill criteria

Reject if:

- it feels like search, maps, or consumer discovery
- it feels too friendly or bubbly
- it becomes visually generic at favicon size

## Concept Set 3: SS Monoline

### Core idea

An abstract monogram based on dual stroke rhythm.

### Prompt/spec version C1

- create a monoline mark using two related curves
- subtly imply `S` and `S` without making them obvious
- keep the geometry quiet and premium

### Prompt/spec version C2

- use one continuous line system with mirrored balance
- suggest dual-signal movement and brand initials
- keep the mark compact and highly reduced

### Prompt/spec version C3

- build a stacked or interlocked monoline symbol
- let the mark feel ownable but not clever
- prioritize clean silhouette over concept complexity

### What to judge

- is it memorable without explanation
- does it feel serious enough for the product
- does it remain legible when very small

### Kill criteria

Reject if:

- it feels too logo-designer-coded
- it requires explanation to be understood
- it becomes decorative instead of structural

## Lockup Rules

When pairing icon and wordmark:

- icon should sit left of `SignalScout`
- icon width should feel slightly smaller than the visual weight of the wordmark
- spacing should feel open, not cramped
- descriptor should be optional, not required

### Descriptor rule

If included, use:

- very small uppercase descriptor
- muted tone
- never let it compete with the main wordmark

The current descriptor should remain secondary at all times.

## Review Grid

For each concept, score from 1-5 on:

1. originality
2. trust
3. precision
4. premium feel
5. small-size clarity
6. homepage fit
7. favicon potential

Any concept scoring below 4 on trust or small-size clarity should not advance.

## Recommended Round 1 Output

Produce:

- 3 `Signal Frame` concepts
- 3 `Scout Lens` concepts
- 2 `SS Monoline` concepts

Total first-pass concepts:

- 8

That is enough range without losing discipline.

## Recommended Decision Rule

Advance only concepts that:

- feel strong in black only
- survive favicon scale
- improve the navbar immediately
- match the current landing page tone
