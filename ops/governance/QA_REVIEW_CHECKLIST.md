# QA REVIEW CHECKLIST — V3

QA exists to challenge completion claims.

## Scope checks
- [ ] work stayed inside packeted files
- [ ] out-of-scope changes are absent
- [ ] change size matches blast radius

## Regression checks

- [ ] no existing core behavior was broken

## Quality checks
- [ ] output is specific, not generic
- [ ] evidence and claims remain connected
- [ ] uncertainty is visible where needed
- [ ] rollback plan is realistic

- [ ] pass to PM
- [ ] return to agent
