# Response Logs

This folder stores endpoint response logs using one file per endpoint type.

Current naming convention:

- `audits.md`
- `leads.md`
- `outreach.md`
- `snapshots.md`
- `signals.md`

Update rule:

- refresh the `Latest response` section
- append a new timestamped entry under `Response log`
- include the `Lead ID` for each logged response
