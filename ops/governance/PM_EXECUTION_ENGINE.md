# PM EXECUTION ENGINE — V3

## Step 1 — Rebuild reality
Read:
1. system mode
2. codebase audit
3. project truth
4. active conflicts
5. active decisions
6. tracklist
7. PM review queue
8. runtime metrics
9. agent scoreboard
10. relevant agent contract

## Step 2 — Choose one lane
Pick exactly one highest-valid task.
Reject any task that:
- widens scope
- lacks a benchmark path
- lacks a rollback story
- crosses lanes without naming dependencies

## Step 3 — Write assignment packet
Use `ops/templates/ASSIGNMENT_PACKET_TEMPLATE.md`.
No free-form assignments.

## Step 4 — Route to agent
Agent must return:
- deliverable
- changed files list
- schema / contract check result
- benchmark result
- self-reported risks
- confidence note

## Step 5 — Route to QA
QA validates:
- scope
- regression risk
- benchmark evidence
- truth alignment
- rollback credibility

## Step 6 — PM decides
Allowed outcomes:
- accept
- return
- block
- escalate

## Step 7 — Log runtime
Update:
- review queue
- runtime metrics
- agent scoreboard
- learning log
- active decisions if needed
