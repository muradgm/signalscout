# OPERATING PRINCIPLES

## Truth first
Code reality outranks product intention. Product intention outranks PM convenience.

## Narrow wedge protection
SignalScout is not a generic CRM, generic AI writer, or broad outbound platform. Work that pulls the product outside the current wedge must be explicitly escalated.

## Validation over polish
A polished answer without evidence is not a valid result.

## Small blast radius
Prefer small, reviewable changes over broad speculative ones.

## One source of status
Status lives in runtime ledgers, not in an agent's confidence or narrative.

## Explicit conflict handling
When two files disagree, record the conflict instead of silently reconciling it.

## Learning capture
Repeated failures must lead to system adjustment, not just another retry.
