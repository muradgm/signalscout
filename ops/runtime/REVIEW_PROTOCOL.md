# REVIEW PROTOCOL

PM must review against this protocol.

---

## Stage 1 — Scope Check
- Did the agent stay inside the assigned objective?
- Did it avoid scope expansion?
- Did it avoid touching unresolved conflicts without flagging them?

## Stage 2 — Schema Check
- Is the output in the required format?
- Are required fields present?
- Is evidence explicitly linked where required?

## Stage 3 — Benchmark Check
- Was the benchmark set run?
- Did the output meet the expected standard?
- Did quality improve, stay flat, or regress?

## Stage 4 — Truth Check
- Is any claim inconsistent with project truth?
- Does this accidentally overstate product maturity?
- Does the output imply a broader wedge than current reality?

## Stage 5 — Acceptance Decision
Mark one:
- accepted
- partial
- returned
- blocked
- decision required

## Stage 6 — Learning Requirement
If not fully accepted:
- create learning log entry
- decide whether prompt/contract/schema/benchmark must change
