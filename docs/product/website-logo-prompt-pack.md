# SignalScout Logo Prompt Pack

## Purpose

This prompt pack is for first-pass logo generation and concept sketching.

It is built from the approved exploration stack:

- [website-logo-directions.md](C:/Users/Murad/Documents/SS/signalscout/docs/product/website-logo-directions.md)
- [website-logo-exploration-board.md](C:/Users/Murad/Documents/SS/signalscout/docs/product/website-logo-exploration-board.md)
- [website-logo-concept-specs.md](C:/Users/Murad/Documents/SS/signalscout/docs/product/website-logo-concept-specs.md)

These prompts are not for final polished brand delivery.
They are for generating strong black-and-white exploration options that can be reviewed side by side.

## Global Prompt Rules

Every prompt should assume:

- black logo on white background
- no gradients
- no shadows
- no 3D
- no mockup presentation
- no paper texture
- no glossy effects
- no AI sparkle motifs

The output should feel:

- premium
- precise
- calm
- modern
- trustworthy

Not:

- playful
- cyber
- generic SaaS
- analytics-tool cliché

## Shared Brand Context

Use this brand context with every concept:

SignalScout is a focused decision workspace for reviewing local-service business websites, surfacing signals, generating grounded audits and outreach drafts, and helping an operator decide the next move. The brand should feel evidence-led, selective, modern, and trustworthy.

## Prompt 1: Signal Frame A1

### Core prompt

Design an original black-and-white logo for SignalScout. Create a minimal rounded-rectangle frame containing one abstract directional signal stroke. The signal should suggest review, judgment, and structured evidence, not analytics or growth charts. Pair it with a clean modern sans-serif wordmark for “SignalScout.” The result should feel premium, precise, simple, and trustworthy.

### Emphasis

- compact frame
- controlled internal signal line
- product-grade geometry
- strong navbar usability

### Negative steering

- no bar charts
- no arrow icons
- no dashboard glyph feel
- no generic startup logo style

## Prompt 2: Signal Frame A2

### Core prompt

Design an original monochrome logo for SignalScout using an implied frame rather than a full border. Use two or three structural frame fragments around a central abstract signal stroke. The form should communicate contained intelligence, review, and operator judgment. Pair it with a sharp, minimal wordmark. Keep the logo calm, premium, and highly usable at small sizes.

### Emphasis

- partial frame construction
- subtle asymmetry
- structured brand feel
- highly reduced geometry

### Negative steering

- no technical wireframe look
- no chart icon language
- no security-shield clichés

## Prompt 3: Signal Frame A3

Keep the mark abstract and brandable rather than descriptive. Pair with a refined sans-serif wordmark. The result should feel like a serious software company, not a feature icon.

### Emphasis

### Negative steering

## Review Instructions

For every generated concept, review against:

1. trust
2. originality
3. navbar fit
4. favicon clarity
5. wordmark balance
6. premium feel
7. homepage fit

Discard anything that:

- needs explanation
- looks generic
- feels trendy instead of durable
- becomes weaker at small size

## Recommended First Run

Generate or sketch first:

1. `Signal Frame A1`
2. `Signal Frame A2`
3. `Scout Lens B2`

Then compare them side by side before exploring the rest.

## PM Recommendation

Use the first run to identify:

- the strongest icon silhouette
- the most natural navbar fit
- the best long-term brand posture

Do not pick based on novelty alone.
Pick the one that makes the product feel most credible.
