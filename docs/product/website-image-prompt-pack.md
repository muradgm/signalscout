Use it to generate:

- hero compositions

- interface-adjacent editorial images

All final imagery must be created exclusively for SignalScout.

This pack is for:

- generation consistency

## Hard Rules

All website visuals must be:

- original
- exclusive to SignalScout
- aligned with the product wedge
- quieter than the product UI

Do not generate:

- stock-photo lookalikes
- humanoid robots
- glowing AI brains
- neon sci-fi environments
- cartoon mascots
- generic 3D SaaS blobs
- fake analytics dashboards
- team-office photography

## Visual Character

SignalScout images should feel:

- editorial
- calm
- tactile
- intelligent
- restrained
- modern

SignalScout images should not feel:

- loud
- playful in a consumer-startup way
- magical for the sake of it
- cyberpunk
- hyper-polished luxury branding
- visually busier than the interface

## Primary Image Families

Use these three image families consistently.

## Family 1: Evidence Board

### Purpose

Support:

- hero compositions
- credibility sections
- product-adjacent story moments

### Visual ingredients

- layered paper-like surfaces
- evidence highlights
- editorial markups
- signal fragments
- restrained annotation marks
- subtle material contrast between paper and screen

### Emotional effect

Feels like:

- reviewed work
- decision support
- careful judgment

## Family 2: Local Signal Texture

### Purpose

Support:

- atmospheric transitions
- background panels
- subtle hero depth
- section separators

### Visual ingredients

- faint locality markers
- abstract map-like traces
- signal paths
- clustered dots
- soft geographic logic without literal maps

### Emotional effect

Feels like:

- relevance
- locality
- signal intelligence

## Family 3: Interface Editorial Still Life

### Purpose

Support:

- hero product framing
- workspace preview sections
- product storytelling panels

### Visual ingredients

- cropped interface surfaces
- layered material framing
- restrained shadow and depth
- thoughtful composition
- sparse annotations

### Emotional effect

Feels like:

- premium internal tool
- product beauty with restraint
- calm operational clarity

## Default Prompt Formula

Use this as the base structure for all prompts:

```text

Asset type: website editorial support image
Primary request: original SignalScout website visual
Scene/backdrop: calm editorial composition with layered tactile materials and restrained depth
Subject: evidence-led local-service review atmosphere, abstract signal and judgment cues, no people
Style/medium: refined editorial digital artwork with product-adjacent realism
Composition/framing: spacious composition with clear focal area and usable negative space for layout
Lighting/mood: soft directional light, calm, intelligent, composed
Color palette: warm bone, paper, stone, graphite, dark olive, muted sage
Materials/textures: paper grain, soft matte surfaces, subtle glass or screen reflections, fine annotation marks
Constraints: elegant, modern, exclusive to SignalScout, quieter than the product UI
Avoid: stock photo look, humanoid robots, neon glow, sci-fi holograms, generic SaaS blob art, cartoon style, loud gradients, busy composition, text, watermark
```

## Variation Strategy

For each family, generate:

- 1 safe direction
- 1 slightly more atmospheric direction
- 1 tighter, more minimal direction

When comparing results, prefer the version that:

- feels most exclusive
- preserves the product's clarity
- supports the page rather than dominating it

## Prompt Adjustment Rules

If an image feels too generic:

- add more tactile material language
- add more editorial composition language
- reduce generic "AI" vocabulary

If an image feels too loud:

- reduce contrast
- reduce visual density
- simplify the subject count
- ask for more negative space

If an image feels too detached from the product:

- add evidence-board language
- add interface-adjacent framing
- reinforce decision-workspace cues

If an image feels too product-heavy:

- remove literal UI details
- keep only material framing and atmospheric support

## Negative Prompt Themes

Keep these themes out across all rounds:

- futuristic control room
- robotic assistant
- glossy B2B hero render
- purple gradient startup art
- literal map software interface
- team collaboration stock scene
- generic corporate success photography
- noisy dashboard collage

## PM Review Checklist

An image direction passes review if:

- it feels original to SignalScout
- it supports the narrow product wedge
- it does not imply platform breadth
- it is calmer than the UI
- it looks usable in a premium but restrained website
- it can coexist with typography without fighting it
